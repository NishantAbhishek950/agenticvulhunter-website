# AgenticVulHunter website

This is a static website, so it does not need Node, React, or a build command.

## Preview locally

From this folder:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Host it

### Vercel

Import the repository as a static site. No framework preset or build command is required.

## Main files

- `index.html` — site content
- `styles.css` — layout and visual design
- `script.js` — copy buttons, mobile menu, and light reveal animations
- `assets/` — logo and preview images

The GitHub links already point to `awsm-research/AgenticBugHunter`.

## Naming note

The public tool name on this website is **AgenticVulHunter**. The current GitHub repository URL and CLI/package identifiers still use `AgenticBugHunter` / `agenticbughunter`, so the install and command examples intentionally keep those technical names until the package itself is renamed.
